# CRM App - ZCLES

Una aplicación de gestión de relaciones con clientes (CRM) simple y eficaz, desarrollada con HTML y JavaScript vanilla. Permite gestionar clientes y sus notas asociadas de manera intuitiva.

## 🚀 Demo en Vivo

Accede a la aplicación: [https://app-zcles-bimgu4ryo-luisernestosalas-2775s-projects.vercel.app](https://app-zcles-bimgu4ryo-luisernestosalas-2775s-projects.vercel.app)

## ✨ Características

- **Gestión de Clientes**: Agregar, editar y eliminar información de clientes
- **Sistema de Notas**: Asociar múltiples notas a cada cliente
- **Interfaz Intuitiva**: Diseño limpio y fácil de usar
- **Almacenamiento Local**: Los datos se guardan en el navegador
- **Responsivo**: Compatible con dispositivos móviles y escritorio

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
