# Documentación Técnica - CRM App ZCLES

## Información General

**Aplicación:** Sistema CRM para gestión de clientes y notas  
**Stack Tecnológico:** HTML + JavaScript (Vanilla)  
**Repositorio:** https://github.com/luisernestosalas/app-zcles  
**URL Producción:** https://app-zcles-bimgu4ryo-luisernestosalas-2775s-projects.vercel.app  
**Plataforma de Deploy:** Vercel  

## Arquitectura

### Frontend
- **HTML5:** Estructura semántica de la aplicación
- **JavaScript Vanilla:** Lógica de negocio y manipulación del DOM
- **CSS:** Estilos y presentación (presumiblemente)

### Características Técnicas
- **Tipo:** Single Page Application (SPA)
- **Persistencia:** LocalStorage del navegador (inferido por el stack)
- **Responsive:** Adaptable a diferentes dispositivos

## Funcionalidades Principales

### Gestión de Clientes
- Registro de nuevos clientes
- Visualización de lista de clientes
- Edición de información de clientes
- Eliminación de registros

### Sistema de Notas
- Creación de notas asociadas a clientes
- Visualización de notas por cliente
- Edición y eliminación de notas
- Búsqueda y filtrado de notas
