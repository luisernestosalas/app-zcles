# Manual de Usuario - CRM App ZCLES

## ¿Qué es esta aplicación?

Es un sistema simple para gestionar clientes y sus notas. Te ayuda a:
- Guardar información de tus clientes
- Añadir notas sobre cada cliente
- Buscar clientes rápidamente
- Mantener organizados tus contactos comerciales

## Cómo acceder

Abre tu navegador web y ve a:
https://app-zcles-bimgu4ryo-luisernestosalas-2775s-projects.vercel.app

## Funciones principales

### 1. Agregar un cliente nuevo
1. Haz clic en el botón **"Nuevo Cliente"**
2. Completa los campos:
   - Nombre completo
   - Teléfono
   - Email
   - Empresa (opcional)
3. Haz clic en **"Guardar"**

### 2. Ver lista de clientes
- En la pantalla principal verás todos tus clientes
- Cada cliente muestra: nombre, teléfono y empresa

### 3. Buscar clientes
1. Usa la barra de búsqueda en la parte superior
2. Escribe el nombre, teléfono o empresa
3. Los resultados se filtran automáticamente

### 4. Ver detalles de un cliente
1. Haz clic sobre cualquier cliente
